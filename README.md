# Q-TEN Clean Website

Built with:
- HTML5
- CSS3
- Bootstrap 5.3.3
- Bootstrap Icons
- Vanilla JavaScript

The homepage hero uses the supplied/generated reference artwork so the visual
composition matches the provided design closely.

The exact Q-TEN logo artwork extracted from the supplied logo PDF is included
as `assets/qten-supplied-logo.jpg`.

Open `index.html` in a browser to run the site.

The enquiry form is a front-end demo and should be connected to a backend/API
before production.
